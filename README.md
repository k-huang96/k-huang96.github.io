# Kun Huang — Academic Website

Source for [Kun Huang's academic website](https://k-huang96.github.io), hosted on GitHub Pages.

This website uses the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll theme.

## Updating the website

- Personal information and profile links: `_config.yml`
- Menu links: `_data/navigation.yml`
- Homepage: `_pages/about.md`
- Research: `_pages/research.md`
- Publications: `_pages/publications.md`
- Teaching: `_pages/teaching.md`
- Online CV: `_pages/cv.md`
- Downloadable public CV: `files/Kun_Huang_CV.pdf`
- Sidebar avatar: `images/kh-monogram.svg` (replace with a headshot when desired)

Commit and push changes to the default branch. GitHub Actions publishes the updated site automatically.

The downloadable CV is a public-facing version that excludes personal phone numbers and referee contact details.
